# 第三方规则与许可

AD_Killer_By_NFQUEUE 自有代码按仓库根目录的 [MIT License](../LICENSE) 发布。该许可证不替代第三方
运行库自身的许可，也**不覆盖**通过
`scripts/merge_rules.py`、`--update` 或用户配置下载的第三方过滤规则。

模块 ZIP 不内置第三方规则；`data/cache/` 和 `data/out_rules/` 也被 Git 忽略。若发布者
另行分发合并规则产物，必须自行满足每个上游的署名、相同方式共享、许可证文本和源代码/
首选修改形式等要求。某个聚合列表自身的许可证也不必然消除它所包含上游的义务。

## WebUI 运行时

WebUI 使用 Vue 3。锁定版本见 `frontend/package-lock.json`；Vue 的
MIT 版权与完整许可在构建时从依赖的 `LICENSE` 内联到发布的 `webroot/index.html`
注释中，不被项目自身的 MIT 声明替代。Vite、Vue 编译插件、singlefile 与 Rollup
仅在电脑/CI 构建使用，不作为手机上的运行依赖。前端构建不下载或捆绑过滤规则。

WebUI 同时使用 GSAP 3.15.0 core/CSSPlugin，其 Standard License 不是 MIT。
按 npm 包保留 GreenSock 版权头、版本、许可名称与链接，构建时内联到 HTML 注释；
关于模块同时列明 Vue / GSAP 的各自许可。没有使用运行期 CDN，不捆绑额外 GSAP 插件。
官方许可：[GSAP Standard License](https://gsap.com/community/standard-license/)。

## 过滤规则

下表于 2026-10-18 按官方仓库/许可页核对，仅用于发布审计，不构成法律意见。

| 合并脚本中的来源 | 官方许可状态 | 发布注意事项 |
|---|---|---|
| AdGuard DNS filter | GPL-3.0 | 保留 GPL 文本、来源和修改说明 |
| AdGuard Mobile / Tracking Protection | GPL-3.0-only | 同上；来源属于 AdGuardFilters |
| EasyList / EasyList China / EasyPrivacy | GPL-3.0-or-later **或** CC BY-SA-3.0-or-later 双许可 | 选择并遵守其中一个许可，按官方要求署名 EasyList authors |
| oisd small | GPL-3.0 | 合并产物发布前保留来源和 GPL 义务 |
| HaGeZi Light / Pro / Fake | GPL-3.0 | `pro - fake` 是修改产物，应标明转换和排除操作 |
| AdRules | 仓库为 0BSD；其 `Source.md` 标明上游许可混合且含 unknown | 不能只凭 0BSD 推定聚合内容均可无条件再分发，需逐项复核 |
| CJX's Annoyance List | LGPL-3.0 | 保留许可、来源和修改说明 |
| 乘风广告过滤规则 | 官方仓库未显示明确许可证 | 默认仅供本地订阅；确认书面许可前不要把其内容打进公开产物 |

| AWAvenue Ads Rule | GPL-3.0 | 保留 GPL 文本、来源和修改说明 |
| hostsVN | MIT | 保留版权和 MIT 许可声明 |
