# 设备基线采集协议

入口是电脑端 `scripts/adb_inspect.py`，需 Python 3.9+、ADB、明确的设备序列号和
手机 root 授权。一次命令只针对指定设备。它不调用已安装模块 CLI，不自动连接其他
设备，也不执行模块启停、安装、卸载、重启、冻结组迁移或防火墙变更。

## 执行与产物

```sh
# 单次只读快照
python3 scripts/adb_inspect.py --serial SERIAL --output dist/inspect-001

# 被动记录：第一份采样完成后计满 86400 秒
python3 scripts/adb_inspect.py --serial SERIAL --output dist/baseline-001 \
  --duration 86400 --interval 60
```

输出目录必须不存在。目录权限为 0700，文件为 0600；`dist/` 不进入 Git。

| 产物 | 内容 |
| --- | --- |
| `run.json` | 采集器摘要、开始/结束时间、目标时长、采样间隔、样本数、失败数、完成状态 |
| `samples.jsonl` | 每行一份有独立时间和读取质量的脱敏 JSON 快照 |

间隔是相邻轮次之间的等待时间，采集自身也消耗时间；每份样本带
`sampling_overhead_ms`。客户端输出与执行时间有界，退出未能确认时中止，不叠加新
ADB 客户端。元数据以独占临时文件、文件同步、原子替换和目录同步保存；最终完成
标志前同步样本文件。中断保留已有记录，完成标志保持 false。

## 字段口径

- **module/device**：版本、versionCode、渠道、模块二进制 SHA-256；映像和启动
  会话采用不含序列号的摘要。模块映像摘要在首轮及每 60 个样本重取一次，不能把
  缺少摘要的中间样本解释为另一份二进制。记录机型、SDK、内核、运行时间与总内存。
- **process**：PID、启动时刻、状态、线程、CPU ticks、RSS/HWM/Data 与进程 I/O。
  只在 PID 文件、前后 `/proc` 启动身份及安装映像一致时标记 owner_verified；
  其他情况不借用旧 PID 的资源数据。
- **delta**：同启动、同 PID/启动时刻、同映像的相邻样本才计算 CPU 与读写差额。
  CPU 百分比以一个核心为 100%，用设备运行时间与 CLK_TCK 计算；跨重启、身份
  变化、倒退或缺失字段返回未知。它是守护进程指标，不包含所有应用/系统功耗。
- **freezer**：读取当前进程完整根层级的 cgroup v1/v2 状态，复核成员和挂载未
  变化。字段缺失、子树挂载、迁移或读取失败为 unknown；不会自动解冻或杀进程。
- **queues**：队列 0/1 的排队、内核/用户丢弃与序号。归属通过 netlink port →
  socket inode → 已验证进程 FD 关联，不把 port ID 当 PID；不能关联时保留 null。
- **routing**：只导出本模块链名、规则数和跳转数。失败、截断或没有可核验的
  命令退出标记时返回未知，不能解释为零条规则。不导出 UID/地址/路由原文。
- **metrics**：只导出允许的数值计数。旧版无会话字段时标为 unverified；新版能
  对应 owner 时也不假造精确新鲜度，因为采集器尚无与模块单调时间戳同源的时钟样本。
- **jobs/logs/disk**：任务文件记录的状态计数，不冒充实时存活结论；仅统计日志
  大小和修改时间，不读取日志正文或 DNS 历史。磁盘记录可用容量，失败为未知。

## 隐私与验收

默认报告不写设备序列号、原始 boot ID、应用名单/UID、上游私有 URL、配置或路由
原文、完整 DNS 历史、规则正文、网络标识或 ADB stderr。不上传数据。配置只保留
模式、作用域、日志/QUIC/自启等状态；采集器不会变更它们。

`run.json.complete` 表示本轮采样记录完成且无传输/root 失败；每个组件仍可能未知，
`acceptance` 明确要求另行检查状态矩阵。它不是“模块健康”“24 小时无异常”或“卸载
无残留”的结论。任务身份核验、完整残留盘点及自动对比汇总仍需后续工具化补齐。

被动采集不生成 DNS 流量，`latency=not_probed`。p50/p95/p99 延迟、低端硬件与
升级/软重启/自启开关/手动暂停/卸载、Wi-Fi/蜂窝/VPN 等矩阵必须另行记录；不能用
Linux 或高内存手机的数据替代低端 Android。状态变更与故障注入等安装包和操作
清单可审核后再执行，不由本工具自动派发。

2026-10-25 已在用户选定的 PKH110、已安装 v1.2.6/12601 上取得真实只读快照，
并启动 24 小时记录。首份快照验证了映像/PID、未冻结及队列 0/1 的 socket 归属，
两队列当时排队和丢弃均为零；当前 RSS 约 6.5 MiB。此记录是优化前版本，不是本轮
未发布代码的效果证明。完整采集结果、时长和缺口以本地报告实际状态为准。
