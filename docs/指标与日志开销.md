# 指标与日志开销

本项属于待优化方案 O06，包含指标快照、空闲缓存维护和 DNS 日志有界异步批量写入。没有宣称已经测得手机省电或延迟改善。

## 指标快照

守护 owner 每秒采样一次，数据变化才发布；相同内容每 15 秒发布一次心跳。`updated_at` 本身不算内容变化，最终退出可强制发布。失败不推进保存检查点，下次采样可重试；错误日志只在失败状态切换时记录。

`metrics.conf` 属于可丢失的观测快照，采用独占临时文件、完整写入及原子 rename，不再逐次 fsync。配置、规则指针、任务状态、生效回执和生命周期意图的持久化行为不受影响。断电可能丢失最新指标，不能拿它作为配置已生效或进程仍在运行的证明。

确定性时钟测试中，一个无流量小时的发布次数从旧策略 3601 次降为 241 次；这是策略测试的次数，并非真机写盘或耗电测量。活动计数仍在下一次一秒采样更新；心跳受 owner 调度影响，并非实时期限。会话归属与过期展示另归 O07。

## 空闲缓存

同一个 owner 周期维护 HTTP/TLS 和 TCP DNS 的未完成前缀，调用线程安全的 prune。没有新包也会按原有超时释放；统计查询仍为只读。原 `idle-retention` 缺陷探针已迁移至 `tests/test_idle_maintenance.cpp`，覆盖超时边界、时钟倒退及两类前缀释放；历史 audit 入口现在运行正确行为回归。

## 待验收

真机仍需对照日志开/关和高查询率下的 p50/p95/p99 延迟、CPU、RSS、写盘与队列丢包。Linux/主机测试不能替代厂商 Android 内核和文件系统的长稳数据。

## DNS 日志缓冲

默认开关及每行格式保持不变。DNS 查询日志路径在收包线程中仅格式化、尝试入队，不为查询日志打开、追加或关闭文件；队列锁竞争时也直接丢弃并计数，不等待写入者。固定字节环形缓冲最多 64 KiB/1024 条，每条最多 640 字节，另有 16 KiB 消费批次及约 2 KiB 长度索引。这里不是整个进程或线程栈的 RSS 上限；关键故障诊断等其他路径不属于这条查询日志缓冲。

开关读取也移出收包线程：使用策略租约保护的已生效值，随启动或成功热重载发布。配置只保存或重载失败时保留旧开关，前端按同一生效回执确认；不会再在第一条 DNS 查询上逐秒打开 `state.conf`。

独立日志线程按最多 250 ms 的等待周期取整条记录，每批最多 16 KiB，沿用原文件大小与轮转上限。较大批次提前唤醒；失败后按 250 ms 至 8 秒退避，避免磁盘满时反复高速重试。队列、批次和错误路径均不保留无限文本。无法启动日志线程时继续守护，未写记录计入丢弃，不把日志失败变成拦截故障。

守护退出先停止收包、释放 NFQUEUE 与响应 socket、清理路由，再关闭日志生产入口并排空尾部，最后保存指标。关闭后的新记录拒绝，最多在 250 ms 排空窗口内派发剩余批次，超时部分计入丢弃。已经开始的文件 syscall 可能受文件系统阻塞，因此没有宣称线程 join 的绝对时限；不会 detach 后继续写已删除数据，操作租约保留至进程真正退出。停止/卸载仍按实际进程及租约核实，不能仅以日志队列清空当作退出完成。

运行指标增加以下计数；均为本次进程的日志记录数，不等于 DNS 包数或广告数：

| 字段 | 含义 |
| --- | --- |
| `dns_log_enqueued` | 已进入缓冲的记录累计数 |
| `dns_log_written` / `dns_log_batches` | append/close 返回成功的记录数 / 批次数；不保证掉电持久化，历史仍按轮转上限保留 |
| `dns_log_dropped` | 未入队、关闭时放弃，以及写入未确认的记录；失败 append 可能已部分写入，不能把此数说成精确缺失行数 |
| `dns_log_write_failures` | 失败或异常的批次写入次数 |
| `dns_log_pending` / `dns_log_pending_bytes` | 尚在缓冲的条数 / 字节，不含正在写的一批 |
| `dns_log_active` | 生产入口是否开放，1/0；日志开关关闭时线程可继续待命 |

这些统计独立采样，瞬时读数不是所有计数的同一原子事务。WebUI 告知繁忙/写入失败可能丢弃，完整计数可从 `--status` / `--status-fast` 的 `metrics` 查看。关闭 DNS 日志后不再入队，但不影响拦截 verdict。

## 2026-10-25 第二阶段验证

严格主机全套、ASan/UBSan（76 项前端）、Playwright 手机/折叠/平板完整界面回归、Android API 31 严格编译、隔离 Linux nft/legacy 完整引擎及完整更新集成通过。缓冲测试覆盖字节环绕与逐条 FIFO、一批多行、阻塞 sink 下生产者仍返回、容量/退出剩余记录上限与异常 sink；真实内核测试在模块专属 tmpfs 注入 ENOSPC，确认 DNS 仍得到 NXDOMAIN、日志失败计数与存储恢复后继续写入，关闭日志不再入队。另验证重载失败或仅修改磁盘配置不提前切换实际日志开关、前端等待精确 ACK、兼容标志 symlink 不改写外部文件。

日志入队会在锁竞争/容量不足时主动丢弃，不能把“异步”宣传成零开销或不丢日志。以上未包含手机 CPU/耗电、厂商内核长稳或真实 p99 对照结果。
