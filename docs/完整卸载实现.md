# 完整卸载实现记录

数据策略已确认：卸载默认删除本模块全部规则、名单、日志、任务记录与下载缓存；升级保留数据。卸载控制器和脚本已接入，真机验收仍待做。本次开发验证不清理已连接手机。

## 已完成的协调基础

- 所有运行数据写入入口持有数据目录外的操作共享租约；外部工具跨 `exec` 继承。关闭入口的标记位于模块目录，迟到请求不再创建数据或锁文件。
- 安装阶段的持久化与任务 admission 锁协调。控制器必须先检查安装屏障，再关闭入口；已派发的安装不能被自动强杀。
- 文件下载与片段预览响应关闭标记。libcurl 同时使用写回调和进度回调，因此无正文的空闲连接也可取消；旧库使用 ABI 匹配的 legacy progress 回调。依据：[libcurl 进度回调](https://curl.se/libcurl/c/CURLOPT_XFERINFOFUNCTION.html)、[启用进度回调](https://curl.se/libcurl/c/CURLOPT_NOPROGRESS.html)。
- 外部 curl/wget 使用独立进程组，保留未回收子进程的 PID 后才终止自己的组，退出确认有界。不确认退出时停止本进程后续下载，保留可能仍被写入的临时文件和租约，不能继续复用文件名。
- 安装器原五分钟强杀改为一次日志提醒，继续等待管理器完成。若无法确认子进程完成，保留 `installing` 日志；只读状态查询仍按同次启动的未知安装处理，不能误报安全终态。

## 删除控制器

`--uninstall` 只接受 root、无附加参数、固定数据/模块路径；模块目录与 `module.prop` 身份须可核实。

1. 模块目录独占锁串行化控制器。在任务 admission 锁内扫描任务记录并核实安装屏障，安装中或同次启动的安装完成状态未知，立即返回 busy，不关闭入口、不暂停守护、不改配置。
2. 持久化模块目录 `.uninstalling` 标记。标记内外复核的普通写入入口拒绝新任务；网络传输可取消，已进入安装的管理器不被中断。
3. 控制器用自己的共享操作租约停止守护，验收双栈模块路由和队列。控制器的子命令也继承租约；关闭自己的共享 FD 后，用另一个 open-file-description 等待独占租约，不能把后代仍持有的共享锁直接转换成独占锁冒充排空。
4. 最多等待 30 秒排空已接受写入者。排空后重新只读核实守护、双栈路由与队列，防止迟到的已接受命令在前一次清理之后改变现场；复查失败保留数据。核实旧模块映像、引用数据的进程参数及可写句柄，兼顾没有新租约协议的旧工具；读取失败、活跃进程或未知所有者均拒绝删除。此扫描只读，不对发现的 PID 发信号。
5. 挂载表检查拒绝数据目录内的普通挂载及同设备 bind mount。fd-relative 预检整个树，锁住所有目录（含旧代际读租约）和 `.lock`/`.lease`，核实归属、类型、设备及 inode；拒绝允许其他用户写入的目录/文件和未知特殊对象。预检最多 32768 项、32 层、512 个目录/文件锁、10 秒；异常或超限保留数据并报错。
6. 再核实模块目录、关闭标记和数据根 inode，使用 `unlinkat` 删除预检的固定树，symlink 只删链接，硬链接只解除目录内链接，不穿越挂载点。不删除共享父目录。删除和目录同步失败报告“未完成/剩余数据保留”，不能承诺已经删除的文件自动回滚。
7. 数据目录删除后，最后移除模块专属外部安装锁、操作锁并同步父目录；关闭标记由管理器移除整个模块目录时清除。重复调用会建立临时控制元数据进行验收，成功后同样不留数据/外部锁；纯查询和迟到写请求不能重新创建它们。

二进制缺失/损坏的脚本兜底只执行有 timeout 的路由读取，不猜 PID、不强删锁、不绕过安装屏障。可重新安装匹配版本后重试。根管理器的目录移除与本控制器不是全局事务，不能与另一个管理器同时安装/卸载同一模块；钩子失败未必阻止管理器移除模块，须按 [ADB 手册](ADB状态检查与卸载残留排查.md)核对残留。

## 本阶段验证

严格主机全套及 ASan/UBSan、Android API 31 严格编译、隔离 Linux 完整更新和 nft 完整引擎集成通过。新增真实 libcurl/exec curl 空闲文件下载及片段预览取消测试，检查旧文件不变、临时文件收回、后续请求仍关闭；新增关闭输出且超过提醒阈值的慢速管理器安装测试，确认自然完成。没有对手机执行卸载、清理或重启。

控制器阶段补充：严格主机全套和 ASan/UBSan、树删除权限/inode/链接隔离的独立 sanitizer 回归、Android API 31 编译通过；隔离 Debian arm64 的 nft/legacy 完整引擎回归、最新控制器双后端集成及完整更新集成通过。真实内核场景包括运行守护 + 空闲同步/单源测试取消、安装临界期及同次启动未知安装拒绝、旧进程可写 FD、孤儿租约、同设备 bind mount、清理查询与排空后复核失败、重复卸载、只读查询及迟到写请求不重建数据。脚本另有实际执行的成功/繁忙/执行失败/缺失二进制回归；兜底只有只读查询。Linux 容器缺少 sanitizer 运行库，没有宣称在容器中执行 ASan；真机与掉电验收未执行。
