# 数据面指标口径与新鲜度

概览主标签为“规则命中”。它按域名匹配次数累计，守护重启重新计数，不是广告数、独立请求数或内核 DROP 总数。

## 计数维度

| 字段 | 口径 |
| --- | --- |
| `block_suffix_hits` / `block_exact_hits` | 后缀/精确黑规则命中的域名次数；同包多个 DNS 问题可命中多次，安全放行或提交失败也保留已发生的匹配 |
| `dns_negative_replies` / `tcp_resets` / `quic_rejects` | 相应否定响应成功提交到发送 socket 的次数，不证明远端一定收到，也不证明原包一定被丢弃 |
| `dns_drop_verdicts` | DNS 队列成功提交 NF_DROP verdict 的次数 |
| `inspected_drop_verdicts` | HTTP/TLS/QUIC 队列成功提交 NF_DROP verdict 的次数 |
| `response_failures` / `verdict_failures` | 快速响应构造/发送失败，以及 verdict/所需连接标记提交失败；响应发送失败不再冒充域名解析失败 |
| `blocked_retransmits` | 历史字段名，表示缓存已判阻断的 TCP 流后续包（含重传）的命中；覆盖 HTTP/TLS 和 TCP DNS，不是 TCP 序列分析后的精确重传次数 |

以上维度不能相加当作“广告拦截总数”。一个 DNS 包可有多次域名命中、一个响应和一个 verdict；QUIC 拒绝没有域名命中；已分类连接的内核 connmark 快路径不会每包经过用户态计数。提交 verdict 成功表示 netlink 发送接口返回成功，不等同于逐包内核执行 ACK 或对端观测证明。

## 会话与快照

新 `metrics.conf` 带 `metrics_format=2`、`owner_boot`、`owner_pid`、`owner_started` 和 `observed_monotonic_ms`。使用 boot ID/PID/启动时刻绑定守护，指标查询前后复核同一进程身份，避免 PID 复用或旧启动的快照混入。元数据是本机归属核验，不是密码学签名。

读取只允许本模块用户拥有、不可被其他用户写入、单硬链接的普通文件，拒绝符号链接和 FIFO，最多 16 KiB。已知数值字段拒绝负数、溢出和重复项；版本 2 必须是完整快照。旧版无会话记录仍可读作历史计数，但不会被标为当前守护。

`--status` / `--status-fast` 的 `metrics` 保留计数字段，增加：

| 字段/状态 | 含义 |
| --- | --- |
| `owner_verified` | 快照属于查询前后核实的当前守护 |
| `age_ms` | 同启动单调时钟下的快照年龄；无法核实时为 null，避免使用可校时的墙钟判断新鲜度 |
| `status=current` / `stale` | 会话已核实，年龄不超过 / 超过 45 秒；正常空闲心跳为 15 秒 |
| `unverified` / `clock_invalid` | 归属、进程观察或单调时间未能核实 |
| `missing` / `unreadable` / `invalid` | 缺失、读取条件不满足或格式不可信，不伪装成成功的零计数 |
| `inactive` | 当前没有运行中的守护，保留文件属于历史 |

查询不创建或修复指标文件。关键配置和生效回执的持久化不受临时指标策略影响。

## 前端呈现

只展示会话已核实的规则命中数；有效零为 `0`，未知为 `—`。过期或查询失败保留可信的上次记录并明确提示；旧会话/错误归属/损坏数据不作为新守护统计。页面用本地单调时钟继续计算接收后的年龄，因此没有新响应也可变为“统计已过期”。离开概览、进入后台和卸载界面时停止定时观察，返回先更新时间与查询。

新 PID 或同 PID 的新启动会话出现时，快速查询不能继承旧健康状态，需完整只读路由/回执核验；不会自动启停或重载引擎。计数、时间、健康和配置生效分别判断，不能以一个新数字代替整体健康证明。

真机的休眠、时钟调整、厂商冻结策略和升级重启仍需验收；本轮不连接手机。

## 本轮验证

严格主机 C++ 与 ASan/UBSan、77 项前端测试、完整 Playwright、Android API 31 严格编译、隔离 Linux nft/legacy 完整引擎及完整更新集成通过。实际 C++ 回调配真实包解析、隔离 netlink/发送结果，覆盖多问题 DNS、响应失败安全放行、响应成功但 verdict 失败、连接标记失败、QUIC 与缓存阻断后续包，确认不混算。最新发送失败分类调整另经该回调 sanitizer 复核。

文件与会话测试覆盖损坏/重复/溢出/负数、16 KiB 上限、symlink/硬链接/FIFO/不可信权限、旧 boot/启动时间、观察中身份变化与时钟边界。真实 CLI 只暂停测试守护，注入旧会话、过期、损坏、缺失及 symlink，恢复后继续运行；手机宽度浏览器验证无新响应时的自动过期，以及未知内容不显示为零。前端新会话、同 PID 新启动与完整查询失败不会自动启停/重载，也不继承旧健康。
